Privacy Policy

OpenAthens Resource Viewer

Last updated: October 27, 2026

This Privacy Policy explains how the OpenAthens Resource Viewer Chrome extension (the “Extension”) handles information while helping users access library electronic resources through OpenAthens.

1. Information the Extension Uses

  • OpenAthens session information: The Extension reads the oa-session cookie associated with my.openathens.net to check apparent sign-in status and display the institution name, when available. The cookie may contain authentication-related information or identifiers. The Extension does not ask users for their OpenAthens password.
  • Available electronic resources: When the database list is opened, the Extension requests resources from https://my.openathens.net/api/v1/services using the browser's existing OpenAthens session. The response may include resource names, descriptions, links and favourite indicators. The content and destination URLs of the links displayed in the database list depend on how the institution has configured OpenAthens.
  • Current webpage URL: When the user clicks “Athenize this URL,” the Extension accesses the URL of the active tab to create a library-configured authentication link. It does not continuously record browsing history.
  • Extension settings: The Extension saves user-selected options, such as the database list display mode, institutional sign-in URL, redirector prefix, Custom SAML rules and proxy-force rules.

2. How Information Is Used

The information above is used only to provide the Extension's features: showing OpenAthens session status, displaying available electronic resources, saving user preferences and generating access links on user request. The Extension does not use this information for advertising, user profiling or analytics.

3. Services That Receive Information

  • OpenAthens: When requesting the database list, the browser communicates with OpenAthens and may send the existing session cookie as part of that request. Opening sign-in and sign-out pages also communicates with OpenAthens or the sign-in service configured by the user.
  • Library-configured authentication services: When the user clicks “Athenize this URL,” the active page URL is incorporated into a new link and opened in another tab. The destination service may therefore receive the original URL, including its path and query parameters. The chosen service may be operated by OpenAthens, a library or another authentication provider.
  • Google Chrome Sync: The Extension uses chrome.storage.sync for settings. If Chrome synchronization is enabled, Google may synchronize these preferences between the user's signed-in browsers under Google's own policies.

The Extension developer does not operate a server that receives session cookies, browsing URLs, resource lists or extension settings, and does not sell or share these data for advertising.

4. Storage and Retention

The Extension does not separately save the OpenAthens session cookie or a browsing-history log to its own storage. Resource-list data is used in the Extension interface during the current view rather than saved as a persistent resource history. Extension preferences remain in Chrome's synchronization storage until changed or removed; any synchronized copies are subject to Chrome's account and data-management controls.

5. Security and User Choices

Connections made directly to the OpenAthens resource API use HTTPS. Authentication is provided by OpenAthens and the relevant institution; the Extension does not independently verify access rights or grant access to resources.

Users can change configuration in the Extension's Settings page and can stop using the Extension by disabling or uninstalling it. Users should avoid selecting “Athenize this URL” on pages whose URLs contain passwords, access tokens or other sensitive information, because the full URL may be sent to the configured authentication destination.

6. External Services

OpenAthens, Google Chrome and any library or authentication services opened by the user have their own privacy practices. This policy covers only the Extension's handling of information and does not govern those external services.

7. Children’s Privacy

The Extension is designed for access to institutional library resources and does not intentionally collect information from children for advertising or profiling.

8. Changes to This Policy

This Privacy Policy may be updated if the Extension's functionality or data practices change. The “Last updated” date above will reflect any changes.

9. Contact

For privacy-related questions, please use the developer contact information provided on the Extension's Chrome Web Store listing.
